## Install the package

```bash
pnpm add @skygenesisenterprise/react-sds
# npm install @skygenesisenterprise/react-sds
# yarn add @skygenesisenterprise/react-sds
```

React is a peer dependency. The package declares `react ^18.0.0`; install it in your
application if it is not already present.

### Optional peers

These peers are optional and only needed when you import the matching entry:

| Entry | Optional peer |
| --- | --- |
| `/native` | `react-native ^0.72.0` |
| `/discord` | `discord.js ^14.0.0` |
| `/Chart/*` | `@gouvfr/dsfr-chart ^1.0.0` |

## Load the stylesheet

The package ships two CSS entry points.

### Complete stylesheet (recommended)

`main.css` loads the SDS foundation **and** the legacy stylesheet that styles the historic
`fr-*` components. Use it whenever you render any of the historic components.

```tsx title="app/layout.tsx"
import "@skygenesisenterprise/react-sds/main.css";
```

### Foundation only

`/styles` loads the SDS tokens, themes, reset, typography, layout and shared component styles,
without the legacy component layer. Use it when you only use the SDS families.

```tsx title="app/layout.tsx"
import "@skygenesisenterprise/react-sds/styles";
```

Both entry points are plain CSS: no Tailwind, Sass or build plugin is required. Individual
stylesheets are also exposed (`/tokens`, `/styles/themes`, `/styles/foundation/*`,
`/styles/components/*`) if you need to compose your own entry.

## Verify the installation

```tsx
import { Button, sdsTokens } from "@skygenesisenterprise/react-sds";

console.log(sdsTokens.colors.primary);
// <Button> works once the stylesheet is loaded
```

If TypeScript cannot resolve the types, make sure `moduleResolution` is set to `bundler` or
`node16`/`nodenext`, so the package `exports` map (including the `types` condition) is used.
