# Foundations — le socle CSS de l'Sky Genesis Enterprise Design System

Depuis **v1.0.6**, `@skygenesisenterprise/react-sds` fournit la **fondation CSS officielle** du
système gouvernemental. Une application n'a plus besoin d'un `globals.css` pour ses
règles communes :

```tsx
// app/layout.tsx — l'import unique de la fondation
import "@skygenesisenterprise/react-sds/main.css";
```

`main.css` charge, dans l'ordre : **tokens → reset → base → typographie → thèmes →
accessibilité → layout → styles de composants → utilitaires**, puis la feuille
historique qui style les classes `fr-*` des composants. La fondation est du CSS
autonome — **Tailwind n'est pas requis** ; les applications restent libres de l'utiliser
pour leurs layouts métier.

Les valeurs affichées ci-dessous sont lues depuis les variables réellement chargées :
elles suivent le thème actif (clair / sombre).

<FoundationsSection title="Themes">
    Les tokens sémantiques basculent avec le thème. Les deux conventions sont
    supportées, à poser sur `<html>` :

    ```html
    <html class="dark">…</html>
    <!-- ou -->
    <html data-fr-theme="dark">…</html>
    ```

    Le choix **light / dark / system** est exposé par le composant `Display` (dialog
    d'affichage du `Header`) et résolu par le runtime (`startReactDsfr`, helpers SSR
    « early color scheme ») : en mode `system`, le runtime écrit la valeur résolue
    dans `data-fr-theme`. Sans runtime, le défaut est le thème clair.

    Les règles de `themes.css` ressemblent à :

    ```css
    .dark,
    [data-fr-theme="dark"] {
        --sds-color-background: oklch(0.2002 0 0);
        /* … */
    }
    ```
</FoundationsSection>

<FoundationsSection title="Accessibility">
    Règles communes centralisées (`accessibility.css`) :

    - `:focus-visible` — anneau de focus toujours visible au clavier ;
    - `.sds-sr-only` — masque visuellement tout en gardant le contenu pour les
      lecteurs d'écran ;
    - `.sds-focus-ring`, `.sds-touch-target` — utilitaires ciblés ;
    - `prefers-reduced-motion` — animations neutralisées, durées à `1ms` ;
    - `prefers-contrast: more` — focus renforcé ;
    - états `:disabled` / `[aria-disabled="true"]` cohérents via les tokens.

    <div style={{ "border": "1px solid var(--sds-color-border)", "borderRadius": "var(--sds-radius-md)", "padding": "1rem" }}>
        <p style={{ "margin": 0 }}>
            Le texte qui suit est invisible à l'écran mais annoncé par les lecteurs
            d'écran : <span className="sds-sr-only">« Ceci est un contenu
            visuellement masqué, réservé aux technologies d'assistance. »</span>
        </p>
    </div>
</FoundationsSection>
