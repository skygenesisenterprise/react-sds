## Props

| Prop | Values | Default |
| --- | --- | --- |
| `label` | `ReactNode` | required |
| `hint` | `ReactNode` | — |
| `nativeSelectProps` | native `<select>` props | required |
| `children` | `<option>` elements | required |
| `state` | `success`, `error`, `info`, `default` | `default` |
| `stateRelatedMessage` | `ReactNode` | — |
| `disabled`, `id`, `className`, `style` | — | — |

## Guidance

- The placeholder option must have an empty `value` so "nothing selected" is detectable.
- For more than ~15 options, use a searchable pattern built on `Input` + a result list.
- For 2–5 mutually exclusive options, `SegmentedControl` or `RadioButtons` is easier to scan.
