```tsx
import { Badge, SDSGrid, SDSStack, Table, Tag } from "@skygenesisenterprise/react-sds";

export function Dashboard({ requests }: { requests: RequestRow[] }) {
  return (
    <SDSStack gap={6}>
      <SDSGrid columns={{ mobile: 1, tablet: 3 }} gap={4}>
        <StatCard label="Open requests" value={128} />
        <StatCard label="Processed" value={1043} />
        <StatCard label="Overdue" value={6} />
      </SDSStack>

      <Table
        caption="Latest requests"
        headers={["Reference", "Applicant", "Status", "Tags"]}
        data={requests.map((row) => [
          row.reference,
          row.applicant,
          <Badge severity={row.severity}>{row.status}</Badge>,
          <Tag small>{row.type}</Tag>,
        ])}
      />
    </SDSStack>
  );
}
```

## Guidance

- **Cards carry one message each.** A metric, a label and a state; no action buttons inside.
- **Tables are for comparison.** Keep the column count low and put the status in a `Badge` so
  it is not conveyed by colour alone.
- **Grid before flex.** `SDSGrid` reflows on mobile without custom media queries.
- **Numbers** should be formatted by your application; the library does not format data.
