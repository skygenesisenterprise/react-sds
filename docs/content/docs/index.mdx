## Documentation scope

- **Source of truth** — the package manifest (`exports`), the published `.d.ts` files and the
  CSS entry points. The API module is generated from the built declarations, so it cannot
  describe an export that the package does not ship.
- **No invented API** — every page only documents what is present in the installed package.
- **Runnable examples** — examples import from `@skygenesisenterprise/react-sds` and are the
  same calls the documentation itself uses.
- **Versioning** — the version shown in this portal is read from the installed package
  manifest. When the library version changes, the reference is regenerated from it.

## Conventions used in this documentation

| Term | Meaning |
| --- | --- |
| SDS | Sky Genesis Enterprise Design System — tokens, styles and components |
| Foundation | The token and stylesheet layer (`/styles`, `/tokens`, `main.css`) |
| Legacy layer | The historic `fr-*` component styles still shipped for compatibility |
| Subpath export | A direct module entry, e.g. `@skygenesisenterprise/react-sds/Button` |
