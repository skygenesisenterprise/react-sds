## Props

| Prop | Values | Note |
| --- | --- | --- |
| `label` | `ReactNode` | Required; the clickable title |
| `children` | `ReactNode` | Required; the panel |
| `defaultExpanded` | `boolean` | Uncontrolled initial state |
| `expanded` + `onExpandedChange` | controlled | Both together |
| `titleAs` | `h2`–`h6` | Heading level of the title |
| `classes` | `root`, `accordion`, `title`, `collapse` | — |

## Controlled usage

```tsx
const [expanded, setExpanded] = useState(false);

<Accordion
  label="Details"
  expanded={expanded}
  onExpandedChange={(next) => setExpanded(next)}
>
  <p>Panel content.</p>
</Accordion>;
```

## Guidance

- Use an accordion for secondary detail, not for the main content of the page.
- Set `titleAs` to the level that follows the surrounding outline.
- Avoid one-item accordions; use a plain heading and paragraph instead.
