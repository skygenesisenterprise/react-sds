## Props

| Prop | Values | Default |
| --- | --- | --- |
| `label` | `ReactNode` | required |
| `hintText` | `ReactNode` | — |
| `hideLabel` | `boolean` | `false` |
| `state` | `success`, `error`, `info`, `default` | `default` |
| `stateRelatedMessage` | `ReactNode` | shown unless state is `default` |
| `textArea` | `boolean` | `false` |
| `nativeInputProps` | native `<input>` props | — |
| `nativeTextAreaProps` | native `<textarea>` props (with `textArea`) | — |
| `disabled`, `iconId`, `classes`, `className`, `style` | — | — |

`addon` and `action` render content after the field (unit, button).

## Guidance

- Always provide `label`; `hideLabel` keeps it for assistive technologies.
- Use `stateRelatedMessage` for the error, not a separate paragraph: it is wired to the field.
- Reserve `state="info"` for neutral guidance and keep `hintText` for instructions.
- `nativeInputProps.type` drives the mobile keyboard (`email`, `tel`, `number`…).
