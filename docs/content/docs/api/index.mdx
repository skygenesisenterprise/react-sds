This module is the exhaustive reference of the public API. Pages under
[Components](/docs/api/components), [SDS](/docs/api/sds), [Hooks](/docs/api/hooks) and
[Utilities](/docs/api/utilities) are **generated** from the TypeScript declarations that ship
in the package (`dist/**/*.d.ts`), and the [exports](/docs/api/exports) page is generated from
the package manifest.

## Why generated

- The reference can only describe symbols the package actually exports.
- Property types and optionality are taken from the declarations, not retyped by hand.
- A library change that is not reflected here makes the documentation check fail in CI.

<Callout type="info">
  Do not edit generated pages. Change the library source or its TSDoc, run `pnpm build`, then
  `pnpm --filter @skygenesisenterprise/react-sds-docs generate`.
</Callout>

## How to read a page

| Section | Meaning |
| --- | --- |
| **Import** | Root import and dedicated subpath, when both exist |
| **Properties** | Name, TypeScript type, required/optional, declared default, TSDoc summary |
| **Exports** | Every symbol exported by the module, with its type |
| **Declaration** | The exact declaration source, for exhaustive variants and unions |

A property marked *optional* may be omitted. "Default" is only shown when the declaration or
its TSDoc states one; an empty default does not mean "undefined by design".

## Modules

- [Components](/docs/api/components) — the web component modules (`…/Button`, `…/Table`, …).
- [SDS](/docs/api/sds) — the SDS families: layout, typography, portal, content.
- [Hooks](/docs/api/hooks) — `useColors`, `useBreakpointsValues`, `useIsDark`, `useConsent`, …
- [Utilities](/docs/api/utilities) — `cx`, `getAssetUrl`, `memoize`, `partition`, …
- [Tokens](/docs/api/tokens/design-tokens) — the token object and its CSS variables.
- [Styles](/docs/api/styles/entry-points) — CSS entry points.
- [Types](/docs/api/types) — shared types (`RegisteredLinkProps`, token types, …).
- [Exports](/docs/api/exports) — every entry in the package `exports` map.

## Version

The reference describes the version installed in this workspace; the portal displays it on the
landing page and in the package manifest page. Optional layers that require extra peers
(`/native`, `/mui`, `/Chart/*`, `/discord`) are documented as such.
