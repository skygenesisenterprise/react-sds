> The institutional portal shell. It provides the institutional identity (organization
name, home link, language) to the header, footer and hero children through context,
and renders a full-height portal wrapper.

```tsx
&lt;SDSPortal organization="Sky Genesis Enterprise">
    &lt;SDSGovernmentHeader />
    &lt;SDSPage>…&lt;/SDSPage>
    &lt;SDSGovernmentFooter />
&lt;/SDSPortal>
```
