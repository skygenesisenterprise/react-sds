## Props

| Prop | Values | Default |
| --- | --- | --- |
| `children` | `ReactNode` | required |
| `severity` | `info`, `success`, `warning`, `error`, `new` | neutral |
| `small` | `boolean` | `false` |
| `noIcon` | `boolean` | `false` |
| `as` | `p`, `span` | `p` |

## Guidance

- A badge is a label, not an action: do not attach `onClick`.
- Keep the label to one or two words ("Validated", "Needs review").
- In a table, use `as="span"` to avoid a paragraph inside a cell.
