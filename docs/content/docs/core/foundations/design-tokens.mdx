The tokens below are rendered from `sdsTokens`, the object exported by the installed package.
Nothing on this page is copied by hand.

```tsx
import { sdsTokens } from "@skygenesisenterprise/react-sds";

sdsTokens.colors.primary;        // "oklch(0.42 0.033 100.6306)"
sdsTokens.spacing[6];            // "2rem"
sdsTokens.breakpoints.md;        // "48rem"
```

## CSS custom properties

Each token is also a CSS variable named `--sge-<group>-<key>`. The prefix is exported as
`cssCustomPropertyPrefix`:

```tsx
import { cssCustomPropertyPrefix } from "@skygenesisenterprise/react-sds";

cssCustomPropertyPrefix; // "sge"
```

```css
.card {
  background: var(--sge-color-surface);
  border: 1px solid var(--sge-color-border);
  border-radius: var(--sge-radius-medium);
  padding: var(--sge-space-4);
  font-family: var(--sge-font-family-base);
  font-size: var(--sge-font-size-md);
  box-shadow: var(--sge-shadow-sm);
}
```

<Callout type="warn">
  The colour values in the `sdsTokens` object are the light-scheme reference values. The
  active scheme resolves at runtime through the CSS variables (see
  [Themes](/docs/core/foundations/themes)), so read `var(--sge-color-*)` in styles rather than
  hard-coding a value from this table.
</Callout>
