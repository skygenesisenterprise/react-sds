## Props

| Prop | Values | Default |
| --- | --- | --- |
| `data` | `ReactNode[][]` | required |
| `headers` | `ReactNode[]` | — |
| `caption` | `ReactNode` | — |
| `noCaption` | `boolean` | `false` |
| `bottomCaption` | `boolean` | `false` |
| `fixed` | `boolean` | `false` |
| `noScroll` | `boolean` | `false` |
| `bordered` | `boolean` | `false` |
| `colorVariant` | colour variant from the stylesheet | — |

## Guidance

- Always provide a `caption`, even if you hide it: it names the table for assistive
  technologies.
- `headers` becomes the `<thead>` row; the same column count must be used in every row.
- Use `fixed` only when the columns have comparable content; otherwise let the table size
  itself.
- On narrow screens, prefer fewer columns over horizontal scrolling (`noScroll` disables the
  wrapper, it does not fix overflow).
