## SDSHeading

| Prop | Values | Note |
| --- | --- | --- |
| `level` | 1–6 (required) | Sets the tag and the default size |
| `size` | 1–6 | Overrides the visual size only |

## SDSText

| Prop | Values | Default |
| --- | --- | --- |
| `as` | `p`, `span`, `div`, `small`, `strong`, `label` | `p` |
| `size` | `xs`, `sm`, `md`, `lg`, `xl` | scale default |
| `weight` | `regular`, `medium`, `semibold`, `bold` | regular |
| `color` | `default`, `muted`, `primary` | `default` |
| `margin` | `none`, `top`, `bottom`, `both` | `none` |
| `align` | `start`, `center`, `end` | inherited |

## SDSLink

- `variant`: `default` (inline), `muted`, `action` (standalone call-to-action with underline).
- `external`: opens in a new tab and sets `rel="noreferrer noopener"`.
- `disabled`: removes `href` and sets `aria-disabled`.
- `iconId`: optional trailing icon for the `action` variant.

```tsx
<SDSLink href="/requests/new" variant="action">Start a request</SDSLink>
<SDSLink href="https://example.com" external>External resource</SDSLink>
```

## Accessibility

- Keep one `<h1>` per page; use `size` instead of skipping a level.
- A link must describe its destination; avoid "click here".
- `SDSText as="label"` does not associate itself with a control — use the form components
  (`Input`, `Select`) which render their own labels.
