The package declares three binaries:

| Binary | Purpose |
| --- | --- |
| `react-sds` | Command dispatcher |
| `copy-legacy-to-public` | Standalone alias of `react-sds copy-static-assets` |
| `only-include-used-icons` | Standalone alias of `react-sds update-icons` (deprecated) |

They are available after installation through your package manager's executor:

```bash
npx react-sds <command>
# pnpm exec react-sds <command>
# yarn react-sds <command>
```

## Commands

| Command | What it does |
| --- | --- |
| [`optimize-css`](/docs/cli/optimize-css) | Rebuilds the legacy stylesheet with only the icons and components your project uses |
| [`copy-static-assets`](/docs/cli/copy-static-assets) | Copies the legacy assets into `public/legacy` (single-page setups) |
| [`update-icons`](/docs/cli/update-icons) | Deprecated — use `optimize-css` |

## Global option

Every command accepts `--projectDir <path>` to point at the React project, which matters in a
monorepo or when the command runs from another directory. It defaults to the current working
directory.

```bash
npx react-sds optimize-css --projectDir ./apps/web
```

## When to use the CLI

- **Vite / CRA**: run `copy-static-assets` before `optimize-css` in `predev`/`prebuild`.
- **Next.js**: static assets are served by the framework; `copy-static-assets` is not needed.
  `optimize-css` remains optional to shrink the legacy stylesheet.
- **Library consumers who do not use historic components**: no command is needed; import
  `/styles` instead of `main.css`.

There is no configuration file and no generator command. The commands read the project on disk.
