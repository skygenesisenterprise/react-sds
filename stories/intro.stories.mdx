This Storybook website is the interactive documentation of **SDS React** —
the official React implementation of the Sky Genesis Enterprise Design System (SDS), the design system for
the digital ecosystem of the Sky Genesis Enterprise.

It not only provides visibility into the available components but also allows you to preview
them in various states, enabling you to copy and paste the code directly into your project.

Additionally, this website features a handy [color helper tool](/?path=/docs/%F0%9F%8E%A8-color-helper--page)
to explore the color decisions of the current stylesheet and pick the shades that fit your use case.

> **Provenance notice:** this project started as a technical fork of the French
> `react-dsfr` library. It is being progressively transformed into an independent design
> system. See the [provenance section](../PROVENANCE.md) of the repository.
