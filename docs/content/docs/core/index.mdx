React SDS is the React implementation of the Sky Genesis Enterprise Design System. It is
distributed as a single package, `@skygenesisenterprise/react-sds`, with three layers:

1. **Foundations** — design tokens exposed as TypeScript values (`sdsTokens`) and as CSS custom
   properties (`--sge-*`), plus the institutional stylesheet.
2. **SDS components** — the design-system families: layout primitives, typography, portal
   chrome and content cards.
3. **Historic components** — the `fr-*` component set (Button, Alert, Table, Tabs, …) that
   remains part of the public API and is still styled by the legacy stylesheet shipped in the
   package.

## What you get

- A tree-shakable package with one module per component, so you can import from the root entry
  or from a dedicated subpath.
- Semantic tokens for colour, typography, spacing, dimensions, radius, elevation, motion and
  breakpoints (see [Design tokens](/docs/core/foundations/design-tokens)).
- Light and dark themes driven by `data-sge-theme`, with the legacy `.dark` and
  `[data-fr-theme="dark"]` selectors honoured.
- TypeScript declarations for every public export; the [API reference](/docs/api) is generated
  from them.
- Optional environment layers that are **not** re-exported by the root entry (Next.js helpers,
  MUI adapter, React Native implementation, Discord tooling), so importing the root never pulls
  an optional dependency.

## Package layout

```text
@skygenesisenterprise/react-sds        root entry (foundations + web components)
@skygenesisenterprise/react-sds/Button  one module per component
@skygenesisenterprise/react-sds/sds     SDS foundations and families
@skygenesisenterprise/react-sds/styles  foundation stylesheet (plain CSS)
@skygenesisenterprise/react-sds/main.css foundation + legacy component styles
@skygenesisenterprise/react-sds/tokens  token custom properties only
@skygenesisenterprise/react-sds/native  React Native implementation (optional peer)
@skygenesisenterprise/react-sds/mui     MUI adapter (optional)
@skygenesisenterprise/react-sds/next-app-router  Next.js App Router helpers
```

The complete list is generated on the [exports reference](/docs/api/exports).

## Requirements

| Requirement | Version |
| --- | --- |
| React | `^18.0.0` (peer dependency declared by the package) |
| Node.js | 18+ for the build tooling and the CLI |
| Optional | `react-native ^0.72.0`, `discord.js ^14.0.0`, `@gouvfr/dsfr-chart ^1.0.0` |
