## Props

| Prop | Values | Default |
| --- | --- | --- |
| `children` | `ReactNode` | required |
| `small` | `boolean` | `false` |
| `as` | `p`, `span`, `button`, `a` | `p` |
| `iconId` | icon class name | — |
| `as="a"` | `linkProps` | — |
| `as="button"` | `dismissible`, `pressed`, `onClick` | — |
| `nativeParagraphProps` | native `<p>` props | — |

`TagsGroup` renders a list of tags: `tags` (at least one `TagProps`), `smallTags`.

## Guidance

- A non-interactive tag is a `<p>` by default; use `as="span"` inside a paragraph or a cell.
- Only tags that remove a filter should be `as="button"` with `dismissible`.
- Keep tag labels short; a tag is not a sentence.
